# Yandex Music to YouTube Music Transfer

Утилита для автоматизированного переноса библиотеки сохраненных треков из Яндекс Музыки в YouTube Music. 

[![Build Executables (Win & Linux)](https://github.com/kordmtal/yandex2ytmusic/actions/workflows/main.yml/badge.svg?branch=improvements)](https://github.com/kordmtal/yandex2ytmusic/actions/workflows/main.yml)
![Python](https://img.shields.io/badge/python-3.10%2B-blue)
[![License](https://img.shields.io/badge/license-MIT-weight)](LICENSE)

## Запуск

### Windows
1. Скачайте файл `yandex2ytmusic.exe` из последнего релиза.
2. Запустите `yandex2ytmusic.exe`.
*(Примечание: фильтр Windows SmartScreen может предупредить о неизвестном издателе. Для запуска нажмите «Подробнее» → «Выполнить в любом случае»).*

### Linux (Ubuntu)
1. Скачайте бинарный файл `yandex2ytmusic` из последнего релиза.
2. Откройте терминал в директории с файлом и выдайте права на исполнение, после чего запустите утилиту:
   ```bash
   chmod +x yandex2ytmusic
   ./yandex2ytmusic
   ```

## Запуск из исходного кода (для Linux / Ubuntu)

Инструкция для разработчиков, желающих запустить скрипт напрямую через интерпретатор Python.

```bash
# Клонирование репозитория
git clone https://github.com/kirillqa17/yandex2ytmusic.git
cd yandex2ytmusic

# Установка Python-зависимостей
pip3 install -r requirements.txt

# Установка Playwright и системных библиотек браузера
pip3 install playwright
playwright install-deps
playwright install chromium

# Запуск
python3 main.py
```

## Инструкция по использованию

Процесс переноса разделен на несколько независимых этапов для предотвращения потери данных и истечения времени сессий.

### Шаг 1. Получение токена Яндекс Музыки

Для того чтобы программа могла прочитать список ваших «Любимых треков», необходимо получить временный ключ доступа (токен).

1. Перейдите по ссылке: [Получить токен Яндекса](https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d).
2. Войдите в свой аккаунт Яндекс и подтвердите доступ.
3. После подтверждения вас перенаправит на главную страницу **Яндекс Музыки**.
4. В этот момент посмотрите на **адресную строку браузера**. Она будет содержать ваш токен и выглядеть следующим образом:
   `https://music.yandex.ru/#access_token=`**`y0_AgAAAABp...`**`&token_type=bearer&expires_in=...`
5. Вам необходимо скопировать только сам токен — это длинный набор символов, который находится **после** `access_token=` и **до** знака `&`.

**Пример:**
> Если в строке браузера указано: `...#access_token=`**`AQAAAAA...`**`&token_type=...`  
> Скопируйте только: **`AQAAAAA...`**

6. Вставьте этот токен в программу при выборе **пункта 2** в главном меню.

> **Важно:** Токен дает временный доступ к вашим данным. Не публикуйте его в открытом доступе и не передавайте третьим лицам.

### Шаг 2. Экспорт из Яндекс Музыки
1. Запустите утилиту и выберите пункт меню `2` (Только экспорт из Яндекс Музыки).
2. Вставьте скопированный токен.
3. Дождитесь окончания процесса. Программа создаст файл `tracks.json` в текущей директории, содержащий список всех сохраненных треков.

### Шаг 3. Настройка авторизации YouTube Music

Для взаимодействия с вашим аккаунтом YouTube Music необходимо передать утилите данные авторизации. **Ручной метод является наиболее надежным способом.**

1. Запустите утилиту и выберите пункт меню `4` (Настроить авторизацию YouTube Music), затем — вариант `2` (Вручную).
2. Откройте браузер Firefox и перейдите на сайт [music.youtube.com](https://music.youtube.com). Убедитесь, что вы авторизованы в своем Google-аккаунте.
3. Откройте инструменты разработчика (клавиша **F12** или **Ctrl+Shift+I**).
4. Перейдите на вкладку **Network** (Сеть).
5. В поле фильтра (Filter) введите слово `browse`.
6. Обновите страницу или совершите любое действие на сайте (например, нажмите на логотип YouTube Music), чтобы в списке появился запрос.
7. Найдите строку с названием `browse?...`, где в колонке **Method** (метод) указано **POST**.
8. Нажмите на этот запрос правой кнопкой мыши и скопируйте заголовки запроса (**Request Headers**):
   - **В Firefox:** Copy Value (Копировать значение) → Copy Request Headers (Копировать заголовки запроса).
9. Вернитесь в окно терминала с запущенной программой.
10. Вставьте скопированный текст.
11. Для завершения ввода нажмите:
    - **В Windows:** `Ctrl+Z`, затем `Enter`.
    - **В Linux:** `Ctrl+D`.

После выполнения этих действий программа создаст файл `browser.json`, который будет использоваться для последующего импорта треков.

### Шаг 4. Импорт треков
1. В главном меню выберите пункт `3` (Только импорт в YouTube Music).
2. Утилита предложит выбрать режим импорта:
   * ### ВНИМАНИЕ: При параллельном импорте более 100 треков YouTube может не сохранить часть лайков!"
   * **Быстрый (параллельный):** добавление треков происходит в несколько потоков. Порядок треков в итоговом плейлисте не гарантируется.
   * **С сохранением порядка:** треки добавляются последовательно. Плейлист в YouTube Music будет полностью соответствовать порядку в Яндекс Музыке.

## Решение возможных проблем

| Ошибка / Проблема | Решение |
|-------------------|---------|
| **Ошибка 401 Unauthorized** | Срок действия сессии YouTube истек. Повторите Шаг 3 (Настройка авторизации), чтобы обновить данные в `browser.json`. |
| **Треки не перенесены** | Из-за различий в региональных лицензиях или названиях некоторые треки могут быть не найдены. Список пропущенных треков доступен в файле `tracks.json` (секция `not_found`). |
| **Ошибка запуска браузера (Linux)** | Убедитесь, что установлены системные зависимости для Chromium. При запуске из исходного кода выполните команду `playwright install-deps`. |
